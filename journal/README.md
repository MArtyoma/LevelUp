# Журнал команды

Сюда пишет каждый: мысли, находки, затыки, что показал плейтест. **Один файл на день**,
`journal/ГГГГ-ММ-ДД.md`, записи — по возрастанию времени.

```bash
./tools/log.sh "Имя" "[затык] TileMap" "Не понимаю слой коллизий, сижу второй час"
```

Нет терминала — допишите в файл дня руками, в том же формате:

```
### 15:40 — Имя — [тема]
Текст.
```

## Правила

1. Запись — 2–5 строк. Длинные никто не пишет и никто не читает.
2. Время и имя автора — обязательно.
3. Писать сразу, а не «потом соберу». Потом не соберётся.
4. **Затык — это тоже запись.** «Не понимаю, как работает TileMap, сижу второй час» ценнее
   половины остального журнала: видно, где команде нужна помощь.
5. Задачи — на доске, решения — в реестре решений, протоколы — отдельно. Журнал — это
   «как мы думали», а не «что мы решили».

Теги для поиска: `[идея]` `[затык]` `[решение]` `[плейтест]` `[находка]`.
Поиск: `grep -rn "затык" journal/`.

Двое пишут в один день — это нормально: Git склеивает такие файлы сам
(`merge=union` в `.gitattributes`), конфликта не будет.
