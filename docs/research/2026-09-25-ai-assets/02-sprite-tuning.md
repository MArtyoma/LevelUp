# 02. Настройка конвейера спрайтов (25.09.2026)

Всё на одном промпте/зерне, смотрели глазами на `sheet.png`.

| # | Что пробовали | Результат |
|---|---|---|
| 1 | Триггер LoRA «transparent background» | **Отрицательный.** Модель рисует шахматку в RGB; заливка от края съела светлую одежду без контура |
| 2 | Сплошной зелёный фон + заливка по цвету рамки | Тень под ногами (тёмно-зелёная) осталась |
| 3 | Хромакей по оттенку (g − max(r,b) > 30) + обдирка каймы 2 px | Фон и тень уходят чисто. Остались замкнутые просветы рука/тело → добавлен проход по сильному оттенку (порог ×3) |
| 4 | Зелёная толстовка / растения на зелёном фоне | **Отрицательный:** вырезаются вместе с фоном. → пурпурный фон, авто по словам в описании |
| 5 | LoRA как есть | В логе ComfyUI «lora key not loaded» ×6 (модуляция, имена diffusers). Так и в 0.31, и в 0.37 |
| 6 | LoRA с переименованными ключами (`fix_lora.py`) | Заливка площе, бликов меньше; фон тусклее и с градиентом — отсюда хромакей по оттенку (3) |
| 7 | Уменьшение: средний цвет клетки + палитра | **Отрицательный:** грязь и шум |
| 8 | Уменьшение: самый частый цвет клетки | Чище и читаемее. Выбрано |
| 9 | Обычные пропорции, 16×32 | Фигура 8 px в ширину, лицо 3 px — не читается |
| 10 | «chibi, big head, short body» | Фигура на всю ширину 16 px; причёска, очки, одежда, предмет читаются. Выбрано по умолчанию |
| 11 | Правка по образцу: спина, профиль в шаге, смена одежды | Персонаж узнаётся во всех трёх. Годится для 4 направлений (право = зеркало лева) |

**Итог:** черновик 16×32 за минуту, узнаваемый силуэт; лицо — «каша», руками доводить
10–15 мин. Кадры анимации и стыкующиеся тайлы не делает.

**Замеры (arrakis, рядом llama-next):** 4 варианта 512×512 — 12–16 с на ComfyUI 0.31,
5–8 с на 0.37; подъём из сна ~12 с; постобработка ~1,5 с на картинку на ноутбуке.
Замеры единичные, без повторов — порядок величины, не точные числа.

**Чего не хватает:** общей палитры (`assets/palette.hex` — решение художника); проверки
на других типах персонажей (дети, животные — не нужны) и на портретах 32×32.
