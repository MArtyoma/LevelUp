# Договорённости

*Короткий список того, о чём иначе спорят на каждом созвоне.*

## Правило, которое дороже всего нарушить

**У каждой сцены `.tscn` один владелец.** Сцены Godot — текстовые файлы, и Git мирит их из рук
вон плохо: двое поправили одну сцену — конфликт, который чинится руками и иногда не чинится
вовсе. Нужно в чужую сцену — напишите в чат «беру `game_ui.tscn`», и владелец её в это время
не трогает.

В репозитории это закреплено дважды: `.gitattributes` запрещает Git пытаться слить сцены
автоматически, `.github/CODEOWNERS` зовёт владельца в pull request.

## Работа с Git

1. **Ветка на задачу.** `git switch -c npc-dialogue`. В `master` напрямую не коммитим.
2. **Перед началом работы — `git pull`.** Каждый раз. Пять секунд против получаса конфликтов.
3. **Коммит — одна законченная мысль**, а не «сохранился на ночь».
4. **Сообщение коммита по-русски, в чём смысл изменения**, а не «fix». Через полгода читать
   будем мы же.
5. **Не коммитим:** папку `.godot/`, сборки, реальные данные заказчика, `.aseprite`.
   Всё это уже в `.gitignore` — просто не добавляйте руками через `git add -f`.

## Код

* **Имена переменных и функций — латиницей и по-английски**, комментарии и тексты — по-русски.
  Не из вкуса: смешанные идентификаторы ломаются в самых неожиданных местах, а объяснять код
  друг другу нам нужно по-русски.
* **Приватное — с подчёркиванием:** `_current_target`, `func _refresh()`. Это значит «снаружи
  не трогать».
* **Отступы — табы** (так принято в Godot, и так настроен `.editorconfig`).
* **Комментарий отвечает на «почему», а не на «что».** `# увеличиваем счётчик` — мусор.
  `# промолчал — считается неверным ответом: дуэль проверяет готовность отвечать сразу` — польза.
* **Строка — до 100 символов.**
* **Документация класса — через `##` в начале файла:** зачем этот файл существует, кто владелец,
  какие решения в нём зашиты.

## Размеры — только из `Grid`

**В коде не должно быть ни одного числа в пикселях.** Ни `60.0` скорости, ни `Vector2(10, 6)`
коробки столкновений, ни `Rect2(112, 0, 16, 16)` региона в атласе. Всё это — доли тайла,
и живут они в `src/core/grid.gd`.

Причина в `docs/architecture.md`, раздел «Размеры». Коротко: иначе смена 16 на 32 означает
найти двадцать чисел по всему проекту, и одно обязательно потеряется.

Поменять размер — четыре шага, они же расписаны в `architecture.md`:

```bash
# Настройки проекта -> Основные -> levelup/grid/tile_size
python3 tools/make_placeholder_art.py
godot --headless --script tools/build_tileset.gd
godot --headless --script tools/rescale_level.gd -- --from=16 --to=32   # только если карта уже собрана
```

Последний шаг правит сцену на месте — **коммит до запуска обязателен.**

## Грабли Godot и GDScript, на которые мы уже наступали

* **Лямбда захватывает локальные переменные по значению.** `var x := ""` плюс `x = "готово"`
  внутри лямбды меняет копию — снаружи останется пустая строка. Собирайте результат в массив или
  словарь: они передаются по ссылке. Поймано в тестах диалогов.
* **`@export`-поля присваиваются до `_ready`.** Если в сеттере обратиться к дочернему узлу
  (`$Sprite2D`), его ещё нет. Проверяйте `is_node_ready()`. Поймано в `npc.gd`.
* **Типизированная переменная падает раньше вашей проверки типа.**
  `var state: Dictionary = data.get("state", {})` уронит игру, если в файле там оказалось
  число, — до того как вы успеете написать `if typeof(...)`. Читая чужой файл, объявляйте
  переменную без типа. Поймано в `quest_log.gd` на испорченном сохранении.
* **`var x := load(...).instantiate()` не компилируется** — тип не выводится. Пишите тип явно.
* **Формы столкновений из сцены — общие для всех копий.** Поправили радиус у одного NPC —
  поменялся у всех шести. Создавайте форму заново в `_ready`, а не правьте подресурс.
* **`_get` — занятое имя** (`Object._get`). Свой метод с таким именем не скомпилируется.
* **Менять `disabled` у формы столкновений посреди кадра физики нельзя** — только
  `set_deferred`. Godot про это честно ругается, но уже в консоли.
* **Физика — только в `_physics_process`.** Нажатия — в `_unhandled_input`, а не в `_input`:
  так кнопки интерфейса получают клавишу первыми, и Enter на варианте ответа не превращается
  заодно в «поговорить» с NPC за окном диалога. А ходить во время разговора игроку не даёт
  не это, а флаг `DialogueRunner.is_running`.

## Как добавить новое, ничего не сломав

| Что нужно | Что править | Кода нужно |
|---|---|---|
| новый сотрудник | `data/company.json` + поставить NPC на карту | нет |
| новый диалог или квест | `data/dialogues.json`, `data/quests.json` | нет |
| новая комната | сцена уровня в редакторе | нет |
| новое **действие** в диалоге | `dialogue_runner.gd` → `_apply_effect`, `data_validator.gd` → `KNOWN_EFFECTS` и `_check_effect`, `docs/data-format.md` | да, три места |
| новое **условие** на варианте ответа | `quest_log.gd` → `check_requirement`, `data_validator.gd` → `KNOWN_REQUIREMENTS`, `docs/data-format.md` | да, три места |
| новый сигнал между системами | `event_bus.gd` | да |
| новый элемент интерфейса | `src/ui/`, подписка на `EventBus` | да |
| другой размер тайла или спрайта | настройки проекта → `levelup/grid`, затем три команды выше | нет |

Если для новой задачи пришлось править больше трёх файлов — скорее всего, её стоит сделать
иначе. Скажите лиду до того, как начнёте.

## Прежде чем отправлять работу

```
godot --headless --script tools/validate_data.gd    # данные целы
godot --headless res://tests/test_runner.tscn       # тесты зелёные
```

То же самое сделает GitHub после push. Локально — просто быстрее.
