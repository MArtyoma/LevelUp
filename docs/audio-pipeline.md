# Звуки и музыка: генерация

Как получить звук или музыкальную петлю для LevelUp одной командой. Написано и для
человека, и для ИИ-агента. Проверено 25.09.2026 на arrakis.

## Что чем делать

| Нужно | Инструмент | Почему |
|---|---|---|
| Писк текста в диалоге, клик меню, «подтвердить/отмена», монетка, «квест выполнен» | `tools/audio/sfxr.py` (алгоритм, без нейросети) | Мгновенно, без тишины в начале, в стиле пиксель-арта, один `.json` — всегда один и тот же звук. Работает без arrakis |
| Шаги, дверь, принтер, кулер, кофемашина, клавиатура | `gen_audio.py --model sfx` (Stable Audio 3 Small SFX) | «Настоящие» звуки, 4 варианта за 4 с |
| Фоновая музыка, эмбиент офиса | `gen_audio.py --model sa-music` / `ace` / `minimax` | См. «Какая модель для музыки» |

Перед генерацией стоит проверить готовые библиотеки с лицензией CC0 (аудиопаки Kenney,
раздел CC0 на Freesound): «шаги по ковролину» там часто уже есть и лучше.

## Быстрый старт

```bash
cd game

# --- ретро-звуки (sfxr) ---
python3 tools/audio/sfxr.py --list                       # пресеты
python3 tools/audio/sfxr.py confirm --count 5            # 5 вариантов -> audio_out/confirm/
python3 tools/audio/sfxr.py talk --name talk_hr --pitch 0.55   # «голос» NPC: у каждого свой pitch
python3 tools/audio/sfxr.py questdone                    # мелодия «квест выполнен»
# понравился вариант 3 — пересобрать ровно его под другим именем (можно поправить .json руками):
python3 tools/audio/sfxr.py --params audio_out/confirm/confirm_03.json --name ui_confirm

# --- звуки (Stable Audio 3 Small SFX) ---
python3 tools/audio/gen_audio.py door_open "office door opening, wooden door, handle click, short creak" --seconds 2

# --- музыка ---
python3 tools/audio/gen_audio.py bgm_office "calm lo-fi office background music, soft electric piano, light brushed drums, warm bass, instrumental, 85 BPM" \
    --model sa-music --seconds 60 --loop
```

Результат — в `audio_out/<имя>/` (каталог в `.gitignore`):

| Файл | Что это |
|---|---|
| `NN.wav` / `NN.ogg` | Готовый файл для Godot |
| `raw_NN.flac` | Что выдала модель, без обработки |
| `sheet.png` | Спектрограммы всех вариантов (у `gen_audio.py`) |
| `meta.json` | Промпт, зерно, модель; для каждого варианта — длина, пик, средняя громкость, флаг `quiet` |
| `*.json` рядом с `.wav` | Параметры sfxr — по ним звук пересобирается побайтно |

Выбрали — копируйте в `assets/sfx/` или `assets/music/` под понятным именем.

**Агенту: вы не слышите звук.** Что можно проверить без ушей — и нужно проверить:
- `meta.json`: `quiet: true` (средняя громкость ниже -45 dB) — вариант почти тишина, выбросить;
- `sheet.png`: чёрная полоса — тишина; ровная серая заливка без структуры — шум;
  у шагов и щелчков видны отдельные вертикальные удары, у музыки — ритмичные штрихи
  ударных и горизонтальные линии нот;
- длина: звук на 0,05 с — скорее всего, модель выдала щелчок, а не то, что просили.

Прошедшие проверку варианты показывайте человеку **на прослушивание**, прямо называя это:
«звук сгенерирован, на слух не проверен». В `assets/` звук кладёт только человек.

## Требования

- Python 3, Pillow и ffmpeg — системный или `pip install imageio-ffmpeg` (так и сделано на saturn).
  `sfxr.py` не нужно ничего, кроме Python.
- Для `gen_audio.py` — ComfyUI на arrakis, как для спрайтов: см. `docs/art-pipeline.md`,
  раздел «Требования» (в том числе как будить `COMFY_WAKE_CMD`).

## Что делает обработка

Модели отдают FLAC (ComfyUI не умеет сохранять WAV), обработка — ffmpeg:

- **Звуки → WAV, 44,1 кГц, моно, 16 бит.** Срезается всё ниже 30 Гц (гул и смещение
  нуля, их видно на спектрограммах шагов). Тишина по краям обрезается: звук играется
  в момент события, и 50 мс задержки уже слышны. Пик выравнивается на -1 dBFS, в конце
  10 мс затухания, чтобы не было щелчка. Моно — потому что в 2D Godot сам разносит звук
  по каналам (`AudioStreamPlayer2D`).
- **Музыка → OGG Vorbis (q6), стерео, громкость -16 LUFS.** OGG Godot зацикливает без
  щелчка. С `--loop` последние 2 с плавно накладываются на первые, файл становится на 2 с
  короче, и конец файла продолжается его началом. В Godot у импорта остаётся включить `Loop`.
  Проверено: скачок на стыке меньше 0,2 обычного шага между сэмплами, то есть щелчка нет.
  **Не проверено**, попадает ли стык в долю такта: на слух петля может «спотыкаться».
  Тогда надо перегенерировать или резать вручную (Audacity) по границе такта.

## Параметры `gen_audio.py`

| Флаг | По умолчанию | Когда менять |
|---|---|---|
| `--model sfx\|sa-music\|ace\|minimax` | `sfx` | См. таблицу выше и «Какая модель для музыки» |
| `--seconds` | sfx 3, музыка 60 | Длина генерации. Звук потом обрезается по тишине |
| `--count` | sfx 4, музыка 2 | 1–8 |
| `--seed` | случайное | Повторить результат — из `meta.json` |
| `--loop` | нет | Музыка: бесшовная петля |
| `--negative` | пусто | Только Stable Audio: чего не должно быть (`vocals, speech`) |
| `--lyrics` | `[Instrumental]` | ace/minimax: текст песни с тегами `[Verse]`, `[Chorus]` |
| `--bpm`, `--key` | 90, `C major` | Только ace: темп и тональность |

`sfxr.py`: пресеты `pickup laser explosion powerup hit jump blip` (как в оригинальном sfxr)
и `talk select confirm cancel footstep` (под нашу игру), мелодии `questdone newquest fail`.
Параметры в `.json` — те же, что в любом sfxr/jsfxr, 0..1; их можно крутить руками.

## Какая модель для музыки

Все три стоят на arrakis. Выбирать надо **на слух, на своих промптах**: независимых
сравнений для инструментальной игровой музыки на 25.09.2026 нет, цифры в статьях —
от авторов моделей.

| Модель | Скорость (2 трека по 45 с) | Лицензия | По отзывам сильна в |
|---|---|---|---|
| `sa-music` — Stable Audio 3 Medium (май 2026) | ~8 с | Stability Community: бесплатно при выручке < $1 млн | эмбиент, фон, инструментал |
| `ace` — ACE-Step 1.5 turbo | ~38 с | MIT/Apache (источники расходятся, обе свободные) | песни с вокалом, скорость |
| `minimax` — MiniMax Music 3 (авг. 2026) | ~6 мин (≈3 мин на трек) | Apache 2.0 (перепаковка Comfy-Org) | целые песни до 5 мин, структура |

**MiniMax сочиняет законченную пьесу**: со вступлением, проигрышем и затухающей концовкой,
и длину выбирает сам (`--seconds 45` дал 29 и 35 с). Для песни это достоинство, для
фоновой петли — нет: пьеса с концовкой зацикливается с провалом. Для петель начинайте
с `sa-music`; у MiniMax берите вариант, у которого на `sheet.png` ровная картина от начала
до конца, или вырезайте середину вручную.

Для ace и minimax варианты — это разные зёрна, отдельные задания: у этих моделей план
музыки сочиняет встроенная языковая модель, и в одном пакете у всех вариантов он был бы
общий. Поэтому они медленнее в пересчёте на вариант.

Промпт для MiniMax по документации ComfyUI лучше писать тремя блоками: `Global Metadata:`
(жанр, BPM, тональность, настроение, где слушают), `Vocal Details:` (для инструментала —
«none»), `Arrangement:` (инструменты, ритм, бас, текстуры).

## Модели на arrakis

| Файл (`/srv/models/comfy/...`) | Что |
|---|---|
| `checkpoints/stable_audio_3_small_sfx.safetensors` | Stable Audio 3 Small SFX, 2,2 ГБ |
| `checkpoints/stable_audio_3_medium.safetensors` | Stable Audio 3 Medium, 8,8 ГБ |
| `text_encoders/t5gemma_b_b_ul2.safetensors` | энкодер обеих Stable Audio |
| `diffusion_models/minimax_music3_dit_fp16.safetensors` | MiniMax Music 3, диффузия |
| `text_encoders/minimax_music3_text_encoder_pruned_bf16.safetensors` | MiniMax Music 3, языковая часть (bf16: int8 «convrot» на ROCm не проверяли) |
| `vae/minimax_music3_dav.safetensors` | MiniMax Music 3, VAE |
| `checkpoints/ace_step_1.5_turbo_aio.safetensors` | ACE-Step 1.5 turbo, всё в одном (стоял раньше) |

Установка с нуля: `scp tools/audio/install_arrakis.sh root@192.168.1.202:/srv/work/ &&
ssh root@192.168.1.202 bash /srv/work/install_arrakis.sh` — ~33 ГБ, sha256, докачка.
MiniMax требует ComfyUI ≥ 0.33; на arrakis с 25.09.2026 стоит 0.37.0 — собственная сборка
поверх образа kyuz0 (`/srv/projects/vault/host/comfyui.Containerfile`, откат одной командой,
описан там же).

## Неполадки

| Симптом | Что делать |
|---|---|
| `нужен ffmpeg` | `pip install imageio-ffmpeg` |
| `ComfyUI вернул ошибку: ... not in list` | Нет файла модели — `tools/audio/install_arrakis.sh` |
| `... MiniMaxMusic3TextEncode ... does not exist` | ComfyUI старше 0.33 — откатили образ? См. Containerfile |
| Все варианты `quiet` | Промпт о тишине/эмбиенте слишком «пустой» — добавить конкретный источник звука |
| Звук обрезан посередине | Порог тишины -50 dB съел тихий хвост — брать `raw_NN.flac` и резать вручную |
